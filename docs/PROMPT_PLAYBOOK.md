# Prompt Playbook

Use short briefs.

## Template

TASK
[Specific change.]

OUTCOME
[Visitor outcome.]

PRESERVE
[Approved behaviours.]

LEAD AUTHORITY
[Authority.]

SKILL
[Relevant skill.]

CONSTRAINTS
[Truth/accessibility/performance/commercial constraints.]

DELIVER
Implement directly.
Do not redesign unrelated sections.
Verify and stop.

## Cesium example

TASK
Build the first-wave Cesium story beat.

OUTCOME
The visitor understands the formation's approach direction and scale.

PRESERVE
Current Story copy and visual language.

LEAD AUTHORITY
EXPERIENCE

SKILL
spatial-story

CONSTRAINTS
Only verified or explicitly approximate historical spatial data.
Do not invent exact trajectories.
Mobile/reduced-motion fallbacks required.

DELIVER
Implement, verify and stop when this beat is complete.
